## Getting Started

### Prerequisites
- Java 25
- Node.js 18
- Maven 4

### Installation
```bash
# clone the repo
git clone <repo-url>
cd <project-folder>

# backend
mvn clean install

# frontend
npm install
```

### Running
```bash
# backend
mvn spring-boot:run

# frontend
npm run dev
```
