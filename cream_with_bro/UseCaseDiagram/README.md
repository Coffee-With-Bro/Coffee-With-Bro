# Use Case Diagram

Contains the UML Use Case Diagrams defining actor interactions, system boundaries, and functional requirements.

---

## Files

- `UseCaseDiagram.drawio`: Editable XML diagram source for diagrams.net (draw.io).
- `UseCaseDiagram.png`: Exported PNG graphic for documentation embedding.

---

## Key Use Cases

- **Primary Actor**: General User / Deaf or Hard-of-Hearing Individual / Signer.
- **Core Use Cases**:
  - Start Webcam Feed.
  - Present Static Hand Sign.
  - Stream Video Frames to Classifier.
  - View Live Translation & Confidence.
  - Manage Accumulated Transcript (Space, Backspace, Clear, Copy).
- **Secondary / Stretch Use Cases**:
  - Custom Sign Recording (Personal dictionary).
  - Confirmation / Correction feedback loop.
